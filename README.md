So you want to run an emulator made completely in C on Windows? Turns out it's pretty hard but fear not! I will guide you.

Quick Start on Windows

Download the project zip and extract it anywhere on your computer

Since we can't run GCC natively on Windows we need to download MSYS2 MINGW64

Download it here: https://www.msys2.org/

and follow all of the default steps then run it:

![steps](image.png)

And now you should see this:

![alt text](image-1.png)

Type this command and run it: pacman -S mingw-w64-x86_64-gcc mingw-w64-x86_64-SDL2 make

Now, we actually need to get Windows to recognize gcc

In the start menu, search: Edit the system enviroment variables

then open it and go to Enironment Variables

![alt text](image-2.png)

Go down to System variables and double click Path

Now click New and add the path to the bin:

C:\msys64\mingw64\bin

![alt text](image-3.png)

now click OK for the two menus and finally in System properties click apply and then OK

Now enter the project folder and compile: 
gcc -O3 -I./c_src c_src/*.c -lmingw32 -lSDL2 -lm -o gmugba.exe

~~On Windows, programs that use SDL2 need SDL2.dll in the same folder as the executable:

Copy SDL2.dll from: C:\msys64\mingw64\bin\SDL2.dll~~ Optional steps if the emu doesn't somehow recognize dsl and refuses to run.

Paste it directly into your project folder next to gdkgba.exe
You can do the same for your
Finally: .\gmugba "Pokemon.gba" "gba_bios.bin"
